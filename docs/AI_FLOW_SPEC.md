# V0.7 AI / Claude Code 交互流程规范

> 本文用于后续 AI 继续维护工程。烦恼分类是交互设计映射，不是心理学诊断。

## 1. 内容层 → 行为层 → 阶段层

- 内容层：`js/worry-data.js` 中 100 个烦恼主题，8 个浏览分类；用户始终可自由输入。
- 行为层：10 个 `behaviorType`。
- 阶段层：`calm` → `growth/transition` → `full chaos` → `erasing` → `return` → `observe`。
- 剧情层：录入 → 删除 → 异常 → 失控 → 独裁者按钮 → 全部删除 → 重现 → 再次删除 → 主动选择 → 观察 → 主题。

## 2. 十种行为

| ID | 名称 | 核心表现 |
|---|---|---|
| B1_LIGHT | 轻散型 | 上浮、轻摆；一击消散并留下细小光点。 |
| B2_ESCAPE | 逃避型 | 靠近就远离；正常阶段第一次点击必定高速躲开，第二次才能删除。 |
| B3_SPLIT | 增殖型 | 正常删除留下 3 个明显分裂残影；失控后真正裂成 2~4 个。 |
| B4_RETURN | 回返型 | 正常阶段就会“删掉后回来”；失控后回返概率进一步升高。 |
| B5_CLUSTER | 聚集型 | 持续抱团；删除一个会把附近 2~3 个对象明显拉向原位置。 |
| B6_STUBBORN | 顽固型 | 更重、更慢、双层边缘；正常至少 2 次点击，失控约 3 次并显示裂纹。 |
| B7_LINKED | 牵连型 | 与最近对象显示虚线连接；删除它会让连接对象突然放大、弹开。 |
| B8_BURST | 突发型 | 周期性高速窜动；正常阶段第一次点击必定冲走，第二次才能删除。 |
| B9_PRESSURE | 压迫型 | 持续变大并有双层脉冲；第一次点击只缩小，继续处理才消失。 |
| B10_BLUR | 模糊型 | 默认明显失焦；靠近会变清晰，直接点击先“看清”，之后才能删除。 |

颜色、说明、100 个预设映射均以 `js/worry-data.js` 为唯一数据源。

## 3. 自由输入规则

1. 用户可输入 1~3 条任意烦恼。
2. “不知道怎么说”只提供灵感，不替代输入框。
3. 选中预设时使用对应 `behaviorType`。
4. 自由输入若无法匹配预设，按权重随机分配一个 `behaviorType`。
5. 前台不显示“系统给你分成了哪一类”，避免变成问卷或心理测评。

```text

→ EMPTY_WORLD
→ WORRY_RETURN

→ EXPERIENCE_SUMMARY
→ RESET / HOME
```

## 5. 节奏规则

### 正常删除
- 最短 14s；成功删除目标 8 次；最长等待 22s。
- 场内维持约 6~10 个泡泡。
- 正常阶段仍保持可控，但不再把 10 类对象做成同一种“一点即删”。
- 每类对象从正常阶段就有明确视觉签名与点击签名；多数类型可在 1~2 次交互内处理，避免过早失控。
- 失控阶段不是更换规则，而是把同一“性格”继续放大。

### 渐变异常
- 约 9s，`transitionProgress: 0 → 1`。
- 特殊行为强度随进度增加。
- 不弹出“第二阶段开始”。先发生异常，后给很短的系统提示。
- 页面边缘红色逐步增强，不整屏硬切。

### 失控
- 不同 `behaviorType` 产生不同结果。
- 自动生成速度继续提高。
- 独裁者按钮满足后台条件后逐渐开放；不要向玩家展示阈值。

### 全部删除
- 所有泡泡原地停止 → 膨胀 → 外圈扩散 → 文字淡出/破碎 → 粒子原地炸裂。
- 禁止向同一中心吸入或压缩。
- 完全清空后保留约 2.5s 空白。

### 重现
- 烦恼逐个重新出现，颜色低饱和、移动更慢。
- 玩家点击后柔和消散，0.8~1.2s 后在别处回来。
- 至少 14s + 6 次尝试后才出现选择。

### 主动选择
- 第一次：`再试一次` / `停下来看看`，视觉权重相同。
- `再试一次` 仅一次，延长约 9s；之后只保留观察方向。
- `停下来看看` 后不直接跳结论：玩家需要从仍在漂浮的泡泡中主动选一个。
- 被选中的泡泡移动到中心，其他泡泡降低存在感，再进入主题页。

## 6. 主题与总结

主题页优先显示玩家主动选中的原始烦恼文本。主题表达：
- “它没有消失。”
- “但你不必继续追着它跑。”
- “有些东西无法通过‘删除’解决。看见它，也许就是另一种开始。”

总结需包含：原始烦恼、正常删除次数、失控删除尝试、明显分裂次数、重现阶段尝试次数、最终观察的烦恼。

## 7. 状态清理

退出 / 重开必须清理：RAF、所有 timeout/interval、泡泡、粒子、重现计时器、选择状态、观察焦点、统计数据、Canvas 事件监听和绘图上下文。第二次体验必须与第一次一致。
