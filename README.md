# 独裁者按钮 · 交互网站 MVP V0.5.2

22世纪未来道具体验馆 No.001《独裁者按钮》桌面端交互网页。

## V0.5.2 定向优化

- “紧急清除协议已开放”后，点击泡泡仍会分裂成 2～4 个子泡泡，不再在 42 个泡泡时直接提示删除被拒绝。
- 自动增殖仍在 42 个泡泡附近停止，点击分裂使用更高的性能保护上限，保证画面继续呈现“越删越多”。
- 移除独裁者按钮下方的椭圆形红色光圈，保留按钮自身的警示色和呼吸效果。
- 烦恼清空后会逐个重新出现，至少呈现 5 个柔和泡泡并恢复全屏点击交互。
- 重现阶段点击泡泡后，泡泡会短暂消散并在其他位置重新出现；完成 3 次尝试后自动进入主题页。
- 删除重现阶段的“继续”按钮，因此不再存在鼠标悬停导致按钮位移的问题。
- 保留 V0.5.1 的全屏直达与退出重进动画修复，其他 UI、阈值与主流程不变。

## V0.5.1 定向修复

- 点击“生成烦恼泡泡”后，UX-06 只在后台完成初始化，前台直接显示全屏删除界面，不再停留于矩形“烦恼正在具象化”页面。
- 修复中途退出后重新体验时，Canvas 绘图上下文未重新建立，导致泡泡停止移动但点击提示仍生效的问题。
- Canvas 每次重新挂载都会重建唯一的动画帧循环，并清除旧场景的延时任务。
- 其余交互流程、视觉效果、阈值和文案保持 V0.5 不变。

## V0.5 核心改动

- UX-07～UX-11 仍保留为后台流程节点，但前台共用同一个全屏 Canvas。
- 正常删除、异常增殖、按钮显现、画面清空与烦恼重现连续发生，不再整页切换。
- 泡泡活动范围扩展到整个交互画面，标题、HUD、退出和按钮区域采用软性排斥，避免长期遮挡。
- `chaosLevel` 根据泡泡数量、生成速度、删除尝试、分裂次数与持续时间综合计算。
- 页面边缘会随 `chaosLevel` 持续渐红，警戒感不再依赖突然切换红色页面。
- 独裁者按钮的临界值只在后台判断，不向用户显示“还需点击几次”。
- 解锁条件改为同时满足：失控持续时间、删除尝试次数、场内泡泡数量。
- 失控阶段单独统计“删除尝试”和“分裂次数”，不再算作删除成功。
- 自动增殖达到 42 个后停止继续堆积，但玩家点击仍可让泡泡继续分裂增长；达到性能保护上限时会回收远处的小泡泡以维持分裂视觉。
- 按下独裁者按钮后，泡泡在当前画面中停止并向按钮收缩，再进入空白。
- 烦恼在空白后逐个柔和重现，完成后显示“真的消失了吗？”，并允许玩家再次点击；泡泡消散后会重新出现。
- 主题页不再显示数字倒计时，最终总结不再强调命中率。

## 运行方式

直接使用 Chrome 或 Edge 打开 `index.html`，无需安装依赖或启动服务器。

## 推荐体验流程

1. 进入体验馆并阅读道具说明。
2. 输入 1～3 条烦恼。
3. 等待泡泡生成。
4. 点击泡泡，完成若干次正常删除。
5. 页面不切换，泡泡开始异常增殖、分裂，边缘警戒色持续增强。
6. 后台条件满足后，紧急清除协议逐渐开放。
7. 按下独裁者按钮，观看泡泡收缩、清空、静止与逐个重现。
8. 再次点击重现的泡泡，观察它们消散后重新出现。
9. 自动进入主题结论与体验记录。

## 主要可调参数

位于 `js/config.js`：

- `GROWTH_START_THRESHOLD`：正常删除转入失控的后台阈值
- `GROWTH_INTERVAL_START_MS` / `GROWTH_INTERVAL_MIN_MS`：增殖生成间隔
- `GROWTH_ACCELERATION_FACTOR`：生成速度加快幅度
- `BUTTON_UNLOCK_MIN_DURATION_MS`：失控阶段最短持续时间
- `BUTTON_UNLOCK_MIN_ATTEMPTS`：失控阶段最少删除尝试
- `BUTTON_UNLOCK_BUBBLE_MIN`：解锁时最少场内泡泡
- `BUTTON_REVEAL_CHAOS_START`：按钮轮廓开始显现的 chaosLevel
- `CHAOS_BUBBLE_FULL` / `CHAOS_ATTEMPT_FULL` / `CHAOS_SPLIT_FULL` / `CHAOS_TIME_FULL_MS`：混乱程度归一化参考值
- `ERASURE_PULL_DURATION_MS`：泡泡向按钮收缩的时长
- `BLANK_HOLD_DURATION_MS`：彻底空白的停留时长
- `RETURN_INITIAL_DELAY_MS` / `RETURN_INTERVAL_MS`：烦恼逐个重现的节奏
- `RETURN_INTERACTION_MIN_ATTEMPTS`：重现阶段需要完成的点击尝试次数
- `RETURN_RESPAWN_DELAY_MS`：重现泡泡被点击后再次出现的延迟

## 手动验收重点

- UX-07 进入 UX-08 时，当前可见 DOM 场景仍为 UX-07，画面没有整页切换。
- 泡泡可在整个窗口内移动，不再被矩形框限制。
- 页面边缘随着增殖持续渐红，不突然整屏变色。
- 失控阶段显示“删除尝试”，不会增加正常删除成功数。
- 独裁者按钮不会提前显示完整可点击状态。
- 按钮只有在持续时间、尝试次数、泡泡数量同时满足后才可点击。
- 紧急清除协议开放后，点击泡泡仍会发生分裂，不会在 42 个泡泡时直接拒绝。
- 按钮触发后，泡泡在原画面中向按钮收缩。
- 空白结束后，原始烦恼逐个重新出现，并可再次点击；页面不显示“继续”按钮。
- 返回首页后，计时器、动画帧、泡泡、统计和输入均被清空。
