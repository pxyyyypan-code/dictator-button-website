# 独裁者按钮 · 交互网站 MVP V0.4

22世纪未来道具体验馆 No.001《独裁者按钮》桌面端交互网页。

## 当前已实现

- UX-01～UX-14 单页场景流程
- 烦恼输入、校验、删除与确认
- 根据用户文字生成 Canvas 泡泡
- 泡泡随机漂浮、边界反弹与文字显示
- 鼠标点击命中、删除动画、粒子反馈与统计
- 删除达到阈值后自动进入“烦恼增殖”阶段
- 增殖阶段的泡泡生成间隔持续缩短，速度越来越快
- 增殖阶段点击泡泡时，母泡泡分裂为 2～4 个较小泡泡
- 分裂时包含向外散开的运动、粒子和扩散圆环反馈
- 达到条件后解锁独裁者按钮
- 独裁者按钮触发、画面清空、烦恼柔和重现
- 主题文案最短阅读时间控制
- 个性化体验总结、退出确认与数据重置
- `prefers-reduced-motion` 动效降级

## 运行方式

直接使用 Chrome 或 Edge 打开 `index.html`，无需安装依赖或启动服务器。

## 推荐体验流程

1. 进入体验馆并阅读道具说明。
2. 输入 1～3 条烦恼。
3. 等待泡泡生成。
4. 点击删除 5 次，进入增殖阶段。
5. 在增殖阶段继续点击，观察泡泡分裂和生成速度加快。
6. 删除次数达到 10 次后，进入独裁者按钮场景。
7. 按下按钮，观看清空、重现与主题总结。

## 可调参数

位于 `js/config.js`：

- `MAX_WORRIES_MVP`：最多输入条数
- `INITIAL_BUBBLE_COUNT`：初始泡泡数量
- `MAX_BUBBLES`：场内泡泡数量上限
- `GROWTH_START_THRESHOLD`：进入增殖阶段所需删除次数
- `GROWTH_INTERVAL_START_MS`：增殖阶段最初的生成间隔
- `GROWTH_INTERVAL_MIN_MS`：加速后的最短生成间隔
- `GROWTH_ACCELERATION_FACTOR`：每次生成后间隔缩短比例，数值越小加速越明显
- `GROWTH_INITIAL_BURST_COUNT`：进入增殖阶段时立即生成的泡泡数量
- `SPLIT_MIN_CHILDREN` / `SPLIT_MAX_CHILDREN`：点击后分裂数量范围
- `SPLIT_CHILD_RADIUS_FACTOR_MIN` / `MAX`：子泡泡相对母泡泡的尺寸范围
- `SPLIT_SPEED_MIN` / `MAX`：分裂后向外散开的速度范围
- `BUTTON_UNLOCK_THRESHOLD`：独裁者按钮解锁所需删除次数
- `CLEAR_ANIMATION_MS`：清空阶段时长
- `THEME_MIN_READ_MS`：主题文案最短停留时长

## 手动验收清单

- 空输入不能进入确认页。
- 输入超过3条时出现提示。
- 每条烦恼文字能够显示在泡泡中。
- UX-07 点击泡泡后删除数增加，点击空白不报错。
- 删除5次后自动进入增殖阶段。
- UX-08 进入后立即新增一组泡泡。
- UX-08 定时生成间隔逐渐缩短。
- UX-08 点击一个泡泡后分裂出 2～4 个较小泡泡。
- 分裂时出现粒子与扩散圆环反馈。
- 删除10次后独裁者按钮解锁。
- 独裁者按钮只能触发一次。
- 画面清空后自动进入烦恼重现。
- 主题文案停留5秒后才能查看总结。
- 返回首页后烦恼、删除次数、点击次数、定时器和泡泡全部清空。
- 浏览器控制台无阻断性错误。
