# 独裁者按钮 · 全局可点击薄框架

22世纪未来道具体验馆 No.001《独裁者按钮》 —— MVP V1.0 的场景骨架。

## 当前实现范围

本轮**只做可点击的薄框架**，不实现完整游戏与复杂视觉：

- UX-01 ~ UX-14 全部 14 个场景（单页切换，非 14 个独立网页）
- 每个场景为「标题 + 简单说明 + 按钮」占位
- 下一步 / 返回 / 退出（含确认）/ 重新开始
- 统一场景状态管理（`SCENE_FLOW` + `APP_STATE`）
- 烦恼输入保存到 JavaScript 数组 `appData.worries`

**占位未实现**：泡泡生成、点击删除、烦恼增殖、动画、音效。

## 运行

直接用 Chrome 或 Edge 打开 `index.html` 即可，无需服务器与依赖。

## 场景与状态对应

需求文档 §5.1 定义 12 个 `APP_STATE` 覆盖 14 个 UX 节点，其中
`INPUT_WORRIES` 覆盖 UX-04~05，`BUBBLE_GAME` 覆盖 UX-07~08。

| 场景 | 名称 | APP_STATE |
| --- | --- | --- |
| UX-01 | 进入体验馆 | INTRO |
| UX-02 | 浏览道具介绍 | GADGET_INFO |
| UX-03 | 确认开始体验 | START_CONFIRM |
| UX-04 | 输入烦恼 | INPUT_WORRIES |
| UX-05 | 确认生成 | INPUT_WORRIES |
| UX-06 | 泡泡生成 | BUBBLE_CREATE |
| UX-07 | 点击删除 | BUBBLE_GAME |
| UX-08 | 烦恼增殖 | BUBBLE_GAME |
| UX-09 | 激活按钮 | BUTTON_READY |
| UX-10 | 画面清空 | WORLD_CLEAR |
| UX-11 | 烦恼重现 | WORRIES_RETURN |
| UX-12 | 阅读主题 | THEME |
| UX-13 | 查看总结 | SUMMARY |
| UX-14 | 返回首页 | RESET |

## 手动测试清单

1. 从 UX-01 连续点「下一步」走到 UX-14，控制台无报错。
2. UX-04 空输入点「添加」→ 出现提示，不能进入 UX-05。
3. UX-04 添加超过 3 条 → 出现上限提示。
4. UX-09 连续点两次独裁者按钮 → 只推进一次，第二次显示「已忽略」。
5. 任意场景点「退出体验」→ 出现确认框 → 确认后回到 UX-01 且烦恼清空。
6. UX-14 点「重新开始」→ 回到 UX-01，UX-04 列表为空。
